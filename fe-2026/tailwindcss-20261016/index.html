让我们开始学习 tailwind

Tailwind 是**实用优先（utility-first）**的 CSS 框架，不提供预设组件，而是内置大量原子化 CSS 类。直接在 HTML 上加类名（如`p-4 bg-blue-500`）就能写样式，不用单独写 css 文件。 优势：开发快、不用自定义命名 css 类；配合 JIT 模式，打包只保留用到的样式，体积很小。 短板：HTML 会变得臃肿，需要记忆大量工具类，复杂组件要自己封装。
