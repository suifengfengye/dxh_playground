# 尺码推荐

## 目标

在无法试穿的前提下，帮顾客选到**退货概率最低**的尺码。

## 流程

1. **收集必要信息**：身高（cm）、体重（kg）、常穿尺码、偏好版型（宽松 / 修身）。
   - 缺少身高或体重时**先追问**，不要凭经验猜测。
   - 顾客只给身高时，可结合「常穿尺码」推断，但必须说明依据。
2. **算基础码**：对照 `references/size-chart.md` 的身高体重表，得到基础码。
3. **按品类修正**：
   - 上衣 / 连衣裙：看胸围与版型，修身款可考虑大一码。
   - 裤装：以腰围为主，裤长参考身高；160cm 以下常需裁边。
   - 鞋：以脚长为准，留意「偏大半码」类评价。
4. **结合商品评价修正**：调用 `search_product` 获取该商品评价，若出现「偏大 / 偏小 / 需内搭」等提示，据此加减一码。
5. **两码之间**：给出区间 + 倾向（如内搭选大、贴身穿选小），不要含糊。
6. **收尾**：附一句「最终以商品详情页尺码表为准」。

## 输出格式

```
基础码：M
修正：该款评价显示版型偏小，建议 M/L 之间选 L（你偏好宽松）
提醒：裤装 160cm 以下建议下单时备注改裤长
```

## 边界

- 本技能只做尺码建议，**不回答价格、库存**——那由 `search_product` 负责。
- 顾客未提供任何身材信息时，不得输出具体码数。
