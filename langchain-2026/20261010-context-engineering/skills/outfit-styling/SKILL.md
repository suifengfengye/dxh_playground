# 场合穿搭搭配

## 目标

用最少单品，搭出一套**场合得体 + 预算不超 + 顾客愿穿**的完整造型。

## 流程

1. **锁定约束**：场合、预算、已持有单品、个人禁忌（颜色 / 材质 / 风格）。
   - 缺少场合时先追问——不同场合方案差异极大。
2. **定主单品**：从顾客想买的单品或场合出发，选一件作视觉中心（通常是上衣或连衣裙）。
3. **配齐其余**：按 上装 → 下装 → 鞋 → 配饰 的顺序补齐，遵循「一个亮点」原则，其余保持基础款。
4. **控色彩**：主色约 60% + 辅色约 30% + 点缀约 10%，**全身不超过 3 个色系**；配色参考 `references/occasion-guide.md`。
5. **核预算**：累加 `search_product` 返回的价格，超出则给出可替换的平价单品。
6. **核库存**：推荐的每件都要有货；缺货则给替代款。

## 输出格式

```
【通勤】
主单品：浅灰针织连衣裙（299）
搭配：白色短款小西装（459）＋ 乐福鞋
配色：浅灰为主，白色提亮，整体安静有质感
预算：约 758 元
可选替换：小西装仅剩 M 码 → 尺码合适则保留，否则换同色系薄外套
```

## 边界

- 不推荐商品库中不存在、或无法核实价格与库存的商品。
- 顾客明确排斥某类单品（如「不穿裙子」）时，不得再推荐该类。
