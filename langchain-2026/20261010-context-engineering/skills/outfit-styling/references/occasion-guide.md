# 场合 - 风格对照（演示用）

| 场合 | 基调 | 推荐配色 | 关键单品 |
|---|---|---|---|
| 通勤 | 干净利落 | 灰 / 白 / 藏蓝 | 针织连衣裙 + 小西装 |
| 约会 | 温柔减龄 | 米白 / 浅粉 / 浅灰 | 连衣裙 + 帆布鞋 + 小方包 |
| 休闲 | 随性日常 | 牛仔蓝 / 白 / 卡其 | 直筒长裤 + 纯色 T 恤 + 帆布鞋 |
| 度假 | 轻松明亮 | 白 / 浅蓝 / 草编色 | 连衣裙 + 草编包 + 遮阳帽 |
| 面试 | 稳重专业 | 黑 / 藏蓝 / 白 | 衬衫 + 西装 + 直筒裤 |

## 配色速记

- 同色系深浅搭配最安全（浅灰 + 深灰）。
- 中性色（黑白灰米）打底，加一个亮色点缀即可。
- 避免同时出现两个以上高饱和色。
