状态多，所以只有"需要你做事"和"已通过"用色；其余保持中性，避免变成彩虹。

Assistant

AI 内容固定三重编码：Assistant 标签 + 左侧 3px 色条 + 浅青底。灰度或色盲环境下依然可辨，不依赖颜色单独表达。

这一条是整套系统的关键约束，不是装饰。

State semantics

  • Pass / Confirmed → success 绿
  • Needs confirmation / 临近截止 → attention 琥珀
  • Gap → 中性（是事实，不是警报）
  • Not stated、结构化结果不可用 → 中性，不显示 0、不用红色
